## About

Pixel Planet Today is a project by Terrabyte. This repository contains the source code for its website: a space-themed landing experience that takes visitors on a journey from orbit down to the Earth's surface as they scroll, plus a hub for everything Terrabyte is working on.

## Features

- **Scroll-driven hero** – A space-themed hero composition that descends closer to the Earth's surface as the user scrolls down the page.
- **Links page** – A Linktree-style hub highlighting Terrabyte projects, Pixel Planet Today posts, and other goodies.
- **Donate** – Redirects to Terrabyte's PayPal donation page.

## Getting Started

### Prerequisites

- [Git](https://git-scm.com/)
- A modern web browser

### Run locally

```bash
# Clone the repository
git clone https://github.com/terrabyte-tech/pixel-planet-today-website.git

# Move into the project folder
cd pixel-planet-today-website
```

If the site is plain static files, open `index.html` in your browser or serve the folder with any static server:

```bash
npx serve .
```

If the project uses a build tool, install dependencies and start the dev server:

```bash
npm install
npm run dev
```
